CIETO — Architecture Diagrams Reference
========================================

This directory contains 6 Draw.io (.drawio) diagrams that document the
system architecture of the Industrial Energy Transition Optimizer.

Open these files with:
  • VS Code "Draw.io Integration" extension (by Henning Dieterichs)
  • https://app.diagrams.net (drag and drop)
  • Draw.io Desktop App


FILE REFERENCE
--------------

| File                         | What It Shows                                            |
| ---------------------------- | -------------------------------------------------------- |
| system_architecture.drawio   | Full layered architecture (Presentation → Application    |
|                              | → Decision Engine → Data Layer) with all components      |
| data_flow.drawio             | Pipeline stages showing how factory data transforms      |
|                              | from input to recommendation report                      |
| decision_flow.drawio         | Flowchart of engine logic with decision diamonds,        |
|                              | parallel scoring branches, and explainability feedback    |
| api_flow.drawio              | Frontend ↔ Backend communication with swimlanes          |
|                              | showing 7 numbered API flows matching backend/apis/      |
| database_er.drawio           | Entity-Relationship diagram for all 7 domain entities    |
|                              | from docs/DOMAIN_MODEL.md with fields and cardinality    |
| deployment.drawio            | Docker Compose 4-container stack (Nginx, Frontend,       |
|                              | Backend, PostgreSQL) with volumes and routing rules       |


COLOR CODING (consistent across all diagrams)
----------------------------------------------

  Blue   (#dae8fc / #6c8ebf)  →  Presentation / User / Frontend
  Green  (#d5e8d4 / #82b366)  →  Application / Backend / Output
  Purple (#e1d5e7 / #9673a6)  →  Decision Engine / Core Logic
  Yellow (#fff2cc / #d6b656)  →  Data Layer / Storage / Knowledge Base
  Red    (#f8cecc / #b85450)  →  Errors / Rejections / "Why Not"
  Gray   (#f5f5f5 / #666666)  →  Infrastructure / Shared / Config


RECOMMENDED READING ORDER
--------------------------

1. system_architecture.drawio    — start here for the big picture
2. data_flow.drawio              — understand the pipeline
3. decision_flow.drawio          — understand the logic
4. api_flow.drawio               — understand frontend ↔ backend
5. database_er.drawio            — understand the data model
6. deployment.drawio             — understand how it runs
