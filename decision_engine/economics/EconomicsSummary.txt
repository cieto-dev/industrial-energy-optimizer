Excellent. This folder answers one simple business question:

> **"If I switch to this technology, will it make financial sense?"**

The optimizer may find a technically feasible solution, but the **economics** module determines whether it's affordable and worthwhile.

---

```text
Technology Selected
```

# 1. capex.py

## What is CapEx?

CapEx = **Capital Expenditure**

It is the **one-time money spent to install** the technology.

Think of buying a car.

Before driving it, you pay:

* Car price
* Registration
* Insurance
* Accessories

That is your initial investment.

Factories are similar.

---

Suppose the factory installs a biomass boiler.

Expenses might be:

| Item            |     Cost |
| --------------- | -------: |
| Biomass Boiler  | ₹20 lakh |
| Installation    |  ₹3 lakh |
| Civil Work      |  ₹5 lakh |
| Piping          |  ₹2 lakh |
| Electrical Work |  ₹1 lakh |

Total

```text
CapEx

=

20 + 3 + 5 + 2 + 1

=

₹31 lakh
```

---

## What does `capex.py` do?

It calculates:

```python
total_capex = (
    equipment_cost
    + installation_cost
    + civil_cost
    + piping_cost
)
```

Output

```json
{
    "capex": 3100000
}
```

---

# 2. opex.py

## What is OpEx?

OpEx = **Operating Expenditure**

Money spent **every day** to operate the system.

Example

Current coal plant

| Expense     | Daily Cost |
| ----------- | ---------: |
| Coal        |    ₹16,000 |
| Labour      |     ₹2,000 |
| Maintenance |       ₹500 |

Total

₹18,500/day

---

Now suppose biomass is installed.

| Expense     | Daily Cost |
| ----------- | ---------: |
| Biomass     |    ₹10,000 |
| Labour      |     ₹2,000 |
| Maintenance |       ₹700 |

Total

₹12,700/day

---

Savings

```text
18,500

-

12,700

=

₹5,800/day
```

---

## What does `opex.py` calculate?

* Fuel cost
* Electricity cost
* Labour
* Maintenance
* Total operating cost

Output

```json
{
    "daily_opex": 12700,
    "annual_opex": 4635500
}
```

# 3. payback.py

This is probably the most important calculation for industries.

Managers ask:

> "If I spend ₹30 lakh today, when do I get it back?"

---

Formula

```text
Payback

=

Investment

/

Annual Savings
```

Example

Investment

₹30 lakh

Annual Savings

₹10 lakh

Therefore

```text
Payback

=

30

/

10

=

3 Years
```

Simple.

---

## Output

```json
{
    "payback_years": 3
}
```

---

# 4. roi.py

ROI

=

Return On Investment

It measures how profitable the investment is.

---

Formula

```text
ROI

=

(Net Profit

/

Investment)

×100
```

Example

Investment

₹30 lakh

Profit after 5 years

₹60 lakh

Net Profit

₹30 lakh

ROI

```text
30

/

30

×

100

=

100%
```

---

Output

```json
{
    "roi": 100
}
```

# 5. economics_engine.py

This is the **manager**.

It doesn't calculate CapEx or ROI itself.

Instead it calls every module.

```text
Scenario

↓

CapEx

↓

OpEx

↓

Savings

↓

Payback

↓

ROI

↓

Economic Summary
```

Internally it might look like:

```python
capex = calculate_capex()

opex = calculate_opex()

payback = calculate_payback(capex, savings)

roi = calculate_roi(...)

return economic_summary
```

# Where do these values come from?

This is an important question.

### CapEx

Sources:

* Vendor quotations
* Manufacturer brochures
* Government reports
* Research papers

Example: Cost of a 1 TPH biomass boiler.

---

### OpEx

Sources:

* `industrial_fuels.csv` (fuel prices)
* `electricity_tariffs.csv`
* Maintenance assumptions
* Labour assumptions

---

### Payback

Calculated from:

```text
CapEx

+

Annual Savings
```

No external dataset needed.

---

### ROI

Calculated from:

```text
Investment

+

Savings

+

Project Lifetime
```

No external dataset needed.

# Summary

| File                  | Responsibility                         | Input                              | Output                    |
| --------------------- | -------------------------------------- | ---------------------------------- | ------------------------- |
| `capex.py`            | Calculate installation cost            | Technology + cost assumptions      | Total CapEx               |
| `opex.py`             | Calculate yearly operating cost        | Fuel use, electricity, maintenance | Annual OpEx               |
| `payback.py`          | Calculate investment recovery time     | CapEx + annual savings             | Payback (years)           |
| `roi.py`              | Calculate return on investment         | Profit + investment                | ROI (%)                   |
| `economics_engine.py` | Orchestrate all financial calculations | Scenario                           | Complete economic summary |

## One improvement I'd suggest

If you're building this for SIH, consider adding a small configuration file (for example, `cost_assumptions.json` or a CSV in your `datasets` folder) that stores default installation costs, maintenance percentages, and project lifetime. Then `capex.py` and `opex.py` can read those values instead of hardcoding them, making it much easier to update assumptions as your research evolves.
